# DevOps Git Learning Project

A practical project demonstrating Git version control and collaboration.

## Collaboration Workflow

- Create feature branches.
- Commit and push changes.
- Review changes through Pull Requests.
- Apply feedback before merging.

## Phase 7: Collaboration

This section demonstrates team collaboration using a second GitHub account.
## Why Use Feature Branches?

Feature branches allow developers to work independently without affecting the main branch. Changes can be reviewed and tested through Pull Requests before merging.
